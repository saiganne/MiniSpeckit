Create a new specification for: "$ARGUMENTS"

Steps:
1. Run `node bin/minispec.js new "$ARGUMENTS"` (or `npx minispeckit new "$ARGUMENTS"`).
2. Open the newly created spec in `specs/`.
3. Fill out Section 1 (Specification: Context, User Story, Acceptance Criteria).
4. Fill out Section 2 (Technical Plan: Architecture, Files, Edge Cases).
5. Outline the step-by-step tasks in Section 3.
6. Present the completed spec to the user for review before writing code.
